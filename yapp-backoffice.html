Tutorial
Como gerir a tua app de forma autónoma
Como alterar fotos
Usar Google Drive para gerir imagens
1
Abre o Google Drive e faz upload da foto que queres usar (arrasta o ficheiro ou clica em "Novo").
2
Clica com o botão direito na foto → "Partilhar" → muda para "Qualquer pessoa com o link" e define como "Visualizador".
3
Copia o ID do link de partilha. O link tem este formato:
https://drive.google.com/file/d/1L9iO5UZa66Fp4p9uuL4jrEW7tgfW5413/view
O ID é a parte a negrito entre /d/ e /view.
4
Constrói o link direto para usar no backoffice:
https://lh3.googleusercontent.com/d/SEU_ID_AQUI
Cola este link no campo de URL da imagem em qualquer secção.
A foto demora até 5 minutos a ficar disponível após a partilha. Se não aparecer, verifica se o ficheiro é público.
Cria uma pasta no Drive chamada "YAPP Fotos" para organizares todas as imagens da app.
Como gerir hóspedes
Adicionar, editar e remover acessos
1
Os utilizadores da app são criados automaticamente quando adicionas uma reserva em Gestão → Reservas. O username é gerado a partir do apelido do hóspede e a password tem 4 dígitos.
2
Partilha o acesso com o hóspede: envia o link da app + o username e password que criaste. O hóspede entra e vê toda a informação da casa.
3
Após o check-out, o acesso expira automaticamente pela data definida. Podes também clicar em "Eliminar" para remover o acesso imediatamente.
4
Usa os filtros (Ativos / Check-in hoje / Expirados) para ver rapidamente quem está a usar a app neste momento.
Para acesso permanente (ex: familiar), usa 2099-12-31 como data de check-out.
Como editar o conteúdo
Quartos, piscina, regras, restaurantes...
1
Navega pela secção que queres editar (ex: Quartos, Piscina, Cozinha). Altera os textos diretamente nos campos.
2
Para alterar fotos, cola o link da imagem no campo "URL da imagem". Ver tutorial de fotos acima para saber como obter o link.
3
Clica em Guardar no fundo de cada secção. As alterações ficam disponíveis na app dos hóspedes em segundos.
4
Gestão → Reservas: para adicionar uma reserva com check-in, check-out e valor. O acesso à app é criado automaticamente e guardado no Google Sheets.
5
Gestão → Receitas: para ver os dados financeiros — receita mensal, gráfico de barras e detalhe por reserva.
6
Gestão → Calendário: mostra os dias ocupados a azul, check-in/out a laranja e dias bloqueados a vermelho (duplo clique para bloquear/desbloquear).
Se saíres sem guardar, o browser avisa-te antes de fechar a página.
Atrações e restaurantes
Adicionar, reordenar e remover pontos de interesse
1
Vai a Atrações ou Restaurantes e clica em "Adicionar". Preenche nome, tipo, distância e descrição.
2
Para as coordenadas GPS, abre o Google Maps, clica com o botão direito no local → copia as coordenadas (ex: 41.7482, -8.1608). Cola a latitude e longitude nos campos.
3
Para reordenar, usa o handle ⠿ à esquerda de cada item — arrasta para cima ou para baixo. Guarda depois de reordenar.
4
Para remover, clica em "Remover" no item. A lista é guardada automaticamente e a atração desaparece da app.
Usa fotos horizontais (landscape) para melhor aparência na app. Tamanho ideal: 800×500px.
Enviar notificações
Comunicar com os hóspedes em tempo real
1
Vai a Notificações e escreve um título e mensagem. Exemplo: "Piscina encerrada hoje para manutenção."
2
Escolhe o destinatário: todos os hóspedes ativos, só os que fizeram check-in hoje, ou um hóspede específico pelo username.
3
Clica em Enviar. A notificação aparece na app dos hóspedes. Podes também adicionar um link para redirecionar para mais info.
Ao adicionar um novo hóspede, uma notificação de boas-vindas é enviada automaticamente.
Alterações técnicas ao backoffice
Password, configurações avançadas e atualizações
1
Alterações técnicas como a password de acesso, atualizações ao layout, novas funcionalidades ou integrações requerem acesso ao código do backoffice.
2
Para qualquer alteração deste tipo, contacta a equipa YAPP diretamente:
geral@yapp.pt
Descreve o que precisas no email e a equipa YAPP trata de tudo sem necessidade de acesso técnico da tua parte.
Organizar o Google Drive
Estrutura recomendada para gerir os ficheiros
1
Cria esta estrutura de pastas no Google Drive:
📁 YAPP — Casa do Gerês
  📁 Fotos — Quartos
  📁 Fotos — Exterior
  📁 Fotos — Atrações
  📁 Fotos — Restaurantes
  📄 Config (Google Sheet)
2
Partilha a pasta principal como pública (só leitura) para que todos os links das imagens funcionem automaticamente.
3
Quando substituíres uma foto, mantém o mesmo nome de ficheiro — o link permanece o mesmo e não precisas de atualizar o backoffice.
O Google Drive oferece 15GB gratuitos — mais que suficiente para centenas de fotos de alta qualidade.
